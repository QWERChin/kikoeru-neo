# 设计决定与开放问题

本页汇总已经实现的产品选择和仍需决定的产品问题。详细行为以链接的章节和接口合同为准，改变既有行为时应同步修改设计、实现和测试。

## 已确定的设计

| 主题 | 决定 | 详细规则 |
|---|---|---|
| 账号与认证 | 不提供匿名模式。导入不保留旧密码，创建、删除账号和重设密码由本地命令完成。网页可以修改自己的密码和退出所有设备。 | [认证与用户](auth.md) |
| 收听状态 | 收藏由用户管理，在听、听过和重听状态由进度得出。听完选定的目录分组即算听过，不要求听完所有格式。 | [数据模型](data-model.md) |
| 多位置作品 | 同一编号合并显示，完全相同的文件只显示一份，不同版本保留各自的目录分组。 | [数据模型](data-model.md) |
| 媒体来源 | 本地、OpenList 和 WebDAV 均只读。远端媒体由后端代理，浏览器不拿网盘直链。OpenList 客户端是独立的公开依赖。 | [存储后端](storage.md) |
| 下载 | 支持单文件、目录和整部作品下载，打包下载不支持断点续传。 | [API 设计](api.md) |
| 标签 | 优先按别名和 DLsite 标签 ID 归并，其余由管理员合并，不提供内置标签词典。 | [扫描与元数据](scanning.md) |
| 元数据 | 默认只用 DLsite，asmr.one 备用来源和 hvdb 声优补充均默认关闭。 | [扫描与元数据](scanning.md) |
| 播放 | 音频支持波形和响度均衡。视频需要回退时生成 HLS，分片沿用媒体 token，ASS 特效由 JASSUB 渲染。 | [媒体处理与播放](media.md) |
| 字体 | 界面使用系统字体。ASS 的中日文回退字体随前端构建，只在需要时加载，作品自带字体优先。 | [前端设计](frontend.md) |
| 数据库 | 默认 SQLite，服务器可选 PostgreSQL，桌面应用的本机模式只用 SQLite。共享查询分别对两个后端编译检查。 | [数据模型](data-model.md) |
| 迁移 | 支持旧版本 0.6.14 到 0.6.17。旧配置只读白名单字段，新导入写空目录，已有库只合并用户数据。 | [迁移](migration.md) |
| 媒体库配置 | 配置文件中的媒体库只读。界面添加的媒体库存入数据库，远端密码单独保存在数据目录中。 | [接口合同](contract.md#媒体库管理接口) |
| 自动扫描 | 默认关闭。最短间隔本地为 5 分钟，OpenList 和 WebDAV 为 30 分钟。本地监听在服务器默认关闭，桌面本机模式默认打开。 | [接口合同](contract.md#自动扫描和目录监听) |
| 评分和短评 | 评分为 1 到 5 星整数，短评最多 2000 个字符，只有本人可见。已评价作品有单独的页面。 | [接口合同](contract.md#评分和短评) |
| HTTP | 支持纯 HTTP 下的核心功能。Service Worker 和离线打开需要安全上下文，网络上的凭据保护由部署者选择 HTTPS 实现。 | [前端设计](frontend.md#纯-http-访问) |
| 桌面应用 | 连接服务器与本机媒体库共用前端。本机模式打包后端和 ffmpeg，macOS 提供 Apple Silicon 构建，Windows 提供安装包，Linux 尽力支持。 | [桌面版](desktop.md) |
| 发布 | Docker 按版本号发布，不使用 `latest`。桌面安装包目前没有开发者证书签名，验证缺口不能由构建成功代替。 | [构建与部署](deployment.md#发布)、[桌面版](desktop.md#构建和发布) |

## 开放问题

- **桌面安装包签名。** 当前不做开发者证书签名，macOS 仅有 ad-hoc 签名。正式引入签名和公证前，需要确定证书管理、工作流凭据和验证步骤。
- **远端写操作。** 当前只读，不开放重命名、上传或删除。若要加入，需要先定义权限、失败恢复和扫描一致性合同，不能直接复用只读接口。

真机验证和实现缺陷属于[路线图](roadmap.md)与[测试与验证](testing.md)中的工作，不再作为待确认的产品默认值。
